# Junior Network Analyst: Zero-Setup Bootcamp

A browser-only classroom tool for running a 90-minute junior network analyst bootcamp with Google Slides, meeting chat, emoji reactions, and free browser-based tools.

## Student Share Link

After GitHub Pages is enabled, share:

```text
https://jjack33.github.io/junior-network-analyst-bootcamp/
```

## Run Locally

Open `index.html` directly in a browser, or serve the folder locally:

```powershell
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Instructor Flow

- 00-10: Warm-Up: Fix or Fail?
- 10-30: Certification Sprint
- 30-45: Choose the Next Command
- 45-65: The Zero-Cost Escape Room
- 65-80: Network Detective
- 80-90: Final Wrap-Up and Mock Challenge

## Hosting

This site is static and has no build step. GitHub Pages can serve it from the `main` branch root.
